# Phase A UX decision screenshots

These screenshots support the iOS Phase A decision request posted to
`ellaaicare/ella-ai#1034` and cross-referenced to `ellaaicare/ella-ai#1019`.

- `today-source-and-talk-cta.png`: Today screen showing both the large
  "Talk to Ella" action and the bottom Voice tab. Both currently open the same
  Ella voice page. It also shows the Ella-source sparkle indicator.
- `memories-source-indicators.png`: Memories list showing the Ella-source
  sparkle indicator on generated summaries.
- `settings-internal-guardian.png`: Internal/debug Settings showing Guardian
  Mode, emergency contact, alert channels, and alert history. These rows are
  hidden when the production build is compiled with `ELLA_PUBLIC_BUILD=true`.

The internal Settings screenshot is not evidence of the public production UI.
It is included to make the retained internal Guardian configuration visible for
the product decision.
