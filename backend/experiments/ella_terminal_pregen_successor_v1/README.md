## Decoded-stock compatibility correction

The actual service SDK represents stock timestamps as `DatetimeWithNanoseconds`, which the former plain JSON fingerprint rejected. The pre-generation branch now uses a closed, typed decoded-stock fingerprint, rejects non-UTC offsets and unsupported values, and leaves legacy completed-result/source hashes unchanged. SDK snapshot decoding/deep-copy can already remove sub-microsecond timestamp digits: this recipe protects the SDK-decoded stock representation, not unseen raw Firestore nanoseconds. Current source/version, account/consent and transactional compare-and-set checks remain required.
